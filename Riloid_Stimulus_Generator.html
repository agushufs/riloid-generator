How each pattern is built

Riloid, exactly as in Zanker (2004, eqs 1–3) and Zanker et al. (2003). x and y are in pixels from the top-left corner, and rotation is applied about the image center first.

I(x,y) = 0.5[1 + sin(2π(x − φ(y))/λ)]
φ(y)   = A·sin(2π·y/μ(y))
μ(y)   = μ_top + y(μ_top − μ_bottom)/(y_top − y_bottom)

λ is the grating period. A is the phase-modulation amplitude, a sideways shift in pixels, so the phase amplitude is 2πA/λ rad. μ is the phase-modulation period, shrinking linearly from the top to the bottom edge (y_top = 0, y_bottom = image height). Turning waviness off sets A = 0, a straight grating. Grey levels run from 0 (black) to 1 (white) as in the paper.

Parameters are in output pixels, as in the papers (512 × 512 images), so keep the output size fixed. Zanker (2004) notes that the meaningful quantity is size relative to λ. Riley's Fall seen from 2 m has λ ≈ 0.37° (about 3 cycles/deg).

Vasareloid and radial grating follow the control patterns of Zanker (2004, Fig. 7), but the paper gives no equations for them. The radial pattern has 128 alternating sectors there (n = 64 cycles here, square wave). The checkerboard with waviness and the vasareloid's smooth check-size variation (x′,y′) = s(r)·(x,y), s = 1 − B(1 − r²/R²) for r < R, are original constructions.

Square-wave edges are antialiased by a linear ramp whose pixel width comes from the analytic phase gradient |∇θ|.
